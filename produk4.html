Casing Server dari Akrilik

Alasan

Casing server dari akrilik adalah wadah pelindung perangkat keras server (seperti motherboard, hard drive, power supply, dan sistem pendingin) yang terbuat dari material plastik polimer transparan (polymethyl methacrylate). Produk ini juga menjadi sarana untuk mengurangi akrilik bekas.

Alat dan bahan

  • Cutter
  • Penggaris
  • Bor
  • Kertas Amplas
  • Obeng
  • Penjepit
  • Lembaran Akrilik
  • Lem Akrilik
  • Spacer
  • Baut
CARA MEMBUAT

Langkah pembuatan

  1. 1

    Ukur dimensi Single Board Computer (seperti Raspberry Pi / Orange Pi) atau motherboard bekas yang akan digunakan sebagai server mini.

  2. 2

    Potong akrilik bekas menjadi 6 sisi kotak casing.

  3. 3

    Bor lubang port (USB, LAN, HDMI) serta dudukan fan pendingin.

  4. 4

    Pasang komponen motherboard dan fan bekas ke dalam akrilik menggunakan baut dan spacer.

  5. 5

    Jalankan mini server untuk hosting web lokal project PPLG.
