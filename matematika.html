IZAM WAHYU FADHILA (21)

Tampilkan perhitungan ⌄

Misalkan

  • x = jam dinding
  • y = tas anyaman

Persamaan paket

x + 2y = 200.00
3x + 5y = 520.000

Penyelesaian

  1. Eliminasi nilai x:
    x + 2y = 200.00
    3x + 5y = 520.000
    persamaan (1) dikalikan dengan 5x + 2y = 200.000 | x5
    persamaan (2) dikalikan dengan 22x + 3y = 520.000 | x2 5x + 10y = 1.000.000
    6x + 10y = 1.040.000
    persamaan tersebut dikurangkan -x = -40.000
    negatif dan negatif diubah menjadi positif x = 40.000
    → x =Rp40.000
  2. Substitusi nilai y ke Paket 1:
    x(40.000) + 2y = 200.000
    40.000 + 2y = 200.000
    2y = 200.000 - 40.000
    2y = 160.000
    160.000 dibagi 2 y =160.000/2
    → y = Rp80.000
Hasil: x(harga 1 jam dinding)=Rp40.000, y(harga 1 tas anyam)=Rp80.000
